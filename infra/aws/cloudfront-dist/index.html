Load Java classes directly from CloudFront CDN with HTTP/2 and range requests. Zero dependencies, virtual threads support.

Block-based ZSTD compression with dependency-aware clustering achieves 27.4% better compression than JAR files.

Stream individual classes from S3 without downloading entire archives. Perfect for microservices and containers.

🔧 Drop-in Replacement

Compatible with existing JAR workflows. Use JarzApplicationClassLoader as a direct URLClassLoader replacement.

Quick Start

CDN Streaming ClassLoader

try (CdnJarzClassLoader loader = new CdnJarzClassLoader("https://cdn.jarz-streaming.net/app.jarz")) { Class<?> clazz = loader.loadClass("com.example.MyClass"); // Use class... }

Create JARZ Archive

java -jar jarz-cli.jar -cf app.jarz -C classes/ .

Upload to CDN

aws s3 cp app.jarz s3://jarz-distribution-1768174356/
